---
title: Map Device User IDs to Students & Teachers
description: Make each fingerprint or card match the right person by keeping device user IDs aligned with eEdu.
---

A device only sends a **user ID** (the number stored on the machine). eEdu matches that number to a student or teacher. Keep the two in sync and attendance is automatic.

<Figure src="/images/docs/diagram-id-mapping.svg" alt="Device user ID matched to an eEdu admission or employee number" caption="One number, two sides — match them and every punch lands on the right person." />

---

## The rule

Use the **same number** on both sides:

| On the device | In eEdu |
| --- | --- |
| Enrolled user ID, e.g. `017` | **Admission no.** (student) or **Employee ID** (teacher) |

---

## Option A — Renumber the device (recommended)

Best for a new install or small corrections.

1. In eEdu, note the student's **Admission no.** (or teacher's **Employee ID**).
2. On the device, re-enroll that person with the matching user ID.
3. Punch once to confirm it shows the correct name in **Punch Logs**.

---

## Option B — Map inside eEdu

Best when re-enrolling is not practical.

1. Go to **`Dashboard → Students → Attendance → Settings → Devices`**.
2. Open the device's **user mapping**.
3. Enter the device user ID and choose the matching student/teacher.
4. Save.

---

## Check it worked

Open **`Dashboard → Students → Attendance → Settings → Devices` → Punch Logs**. Each punch shows **Device user ID**, the matched **Person**, time, direction and status.

- **Processed** → matched to a person.
- **Error / Unmapped** → the ID has no match; map it or re-enroll it.

> [!TIP]
> If two people share a device ID, the later mapping wins. Check the punch log after bulk changes.
