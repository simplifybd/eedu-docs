## 1. Add a teacher's record

`Dashboard → Teachers` → **Add Teacher**:

| Field | What to enter |
| --- | --- |
| **Full name** | as it should appear on registers and payslips |
| **Designation / Department** | e.g. Assistant Teacher · Science |
| **Phone / Email** | email needed for dashboard access |
| **Employee ID** | leave blank — eEdu generates it |
| **Joining date** | first working day |
| **Show on website** | list them on your public “Our Teachers” page |
| **Grant dashboard access** | give them a login (step 2) |

Save. The **Employee ID** (e.g. `000017`) is also the number biometric devices use — see [User ID mapping](/docs/hardware-guide/user-id-mapping).

---

## 2. Give them a login

eEdu picks the right path automatically:

- **Existing eEdu account** → access is granted instantly.
- **New user** → eEdu emails an **invite link** to create a password.

To grant: open the teacher → **Invite / Dashboard access** → choose a role → save. If the link expires, just send a new one.

---

## 3. Set what they can do

`Dashboard → Account → Team Members` (owner only). Each feature is set to:

| Level | Meaning |
| --- | --- |
| **Write** | view **and** change |
| **Read** | view only |
| **Off** | hidden from their menu |

Tick features (**Attendance, Fees, Results, Students, Reports**…), optionally limit a teacher to **specific classrooms**, and save.

> [!TIP]
> Start new teachers on **Read**. Most need only: Attendance, Results, Homework and their own Leave.

---

## 4. My Space (what teachers see)

Each teacher gets a personal **My Space**: profile, attendance and calendar, leave with status, payslips, and their timetable/classes. Members can never see another teacher's salary.

---

## 5. Remove access

Open the teacher → **Archive** (keeps records, drops login). History stays in reports. Re-archiving restores the HR record only — re-grant access separately if they return.
