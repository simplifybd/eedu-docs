## 1. Create the exam term

`Dashboard → Students → Exam Suite` (or **Exam Results**) → **New Term** → name it (e.g. `Half-Yearly 2026`) and set the dates. Add each exam's **schedule** under the class.

---

## 2. Enter marks

1. `Dashboard → Students → Exam Results`.
2. Pick the term and classroom → the student roster appears with each subject's components (CQ / MCQ / Practical / Viva).
3. Enter marks (or **import** from a spreadsheet), leaving a component blank marks it “missing”.

> [!TIP]
> Pass marks and totals come from the subject setup — fix those in [Subjects](/en/docs/school-operations/class-routine-and-timetable) before marks entry.

---

## 3. Check the results

The **Exam Suite** gives you three views:

| View | Shows |
| --- | --- |
| **Tabulation** | all marks in one sheet |
| **Merit list** | ranked students |
| **Seat plan** | room-by-room seating |

Each can be **downloaded as PDF**.

### Seat plan

The seat plan is generated automatically from the exam routine:

1. Create the **exam routine/schedule** (`Dashboard → Students → Timetable → Exam Routine`) with **date, room number, invigilator** and subject.
2. `Dashboard → Students → Exam Suite` → pick the **exam term** and **classroom** → open the **Seat Plan** tab.
3. Seats are filled in roll order (default 10 per row). Download the PDF for printing.

> [!TIP]
> Set the room and invigilator on the exam schedule first — the seat plan header uses them.

---

## 4. Publish

Only the **owner** publishes results. Once published, students and parents see them in their portal under **Academics → Results**, and (if enabled) on the public **Exam Results** page.

Published documents:

- **Marksheet / report card** (downloadable PDF)
- **Tabulation sheet**, **merit list** and **seat plan** for printing

---

## Troubleshooting

| Problem | Fix |
| --- | --- |
| Component marked “missing” | Fill the blank, or it is intentionally absent |
| Result not visible to family | Publish it (owner only) |
| Wrong total | Correct the subject's component totals |
