---

## 1. Set the rules once

`Dashboard → Students → Attendance` → **Settings**:

| Setting | Controls |
| --- | --- |
| Marking mode | one **daily** record, or **period-wise** |
| Late cut-off | time after which a student is **Late** |
| Weekly holidays | days with no attendance |
| Shifts | Morning / Day / Evening timings |

Assign each classroom the right **shift** if you use them.

---

## 2. Mark attendance

1. `Dashboard → Students → Attendance` → **Mark Attendance**.
2. Pick classroom, date and (if period-wise) the period.
3. Tap **Mark all present**, then change only the exceptions: **Present / Late / Absent / Leave**.
4. Save.

> [!TIP]
> With devices installed, punches fill the register for you — you only correct exceptions (forgot to punch, approved leave).

---

## 3. Review & export

From the same screen:

- **Monthly calendar** per student (colour-coded).
- **Class summary** and **low-attendance report**.
- Export the register to **CSV / PDF**.

---

## 4. Absence alerts

`Dashboard → Students → Absence Alerts` → choose the **channel** (SMS / WhatsApp / in-app), set how many absent days trigger an alert, and the message. Send one-off alerts or let it run on schedule.

> [!WARNING]
> Alerts use your institute's SMS/WhatsApp credit — check the sender ID and balance first.

---

## Troubleshooting

| Problem | Fix |
| --- | --- |
| Can't save | Weekly holiday, or no **Write** permission |
| Everyone is Late | Cut-off too early, or device clock wrong |
| Punch missing | See [Offline & sync](/docs/hardware-guide/offline-and-sync-troubleshooting) |
