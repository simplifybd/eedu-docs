The routine drives **period-wise attendance**, teacher schedules and the public routine page.

---

## 1. Check classrooms

`Dashboard → Students → Classrooms` → add any missing class (e.g. `Class 6-A`) with its **shift** and the current **academic year**.

---

## 2. Add subjects

`Dashboard → Students → Subjects` → **Add Subject**. For each subject set its papers:

| Paper | Set |
| --- | --- |
| **CQ** | Total and pass marks (e.g. 50 / 15) |
| **MCQ** | Total and pass marks |
| **Practical** | if applicable |
| **Viva** | if applicable |

> [!TIP]
> Match these to your board handbook — they drive grading and the printed marksheet.

---

## 3. Assign subjects to a class

Open the classroom and add the subjects that class studies. For streams (Science/Business/Humanities), set the **stream group** so the right subjects attach.

---

## 4. Build the weekly grid

`Dashboard → Students → Timetable` → **New Timetable** → choose classroom + term. Fill each **day** and **period**:

| Field | Value |
| --- | --- |
| Period / time | e.g. 08:30–09:20 |
| Subject | from the class list |
| Teacher | who takes it |
| Room | optional |

eEdu **warns about conflicts** (same teacher or class in two periods). Save.

---

## 5. Verify & publish

- Check a teacher's **My Space** shows only their periods.
- Confirm every period is covered.
- Published copies appear on the public site's **Routine** page (if enabled).

---

## 6. Academic events calendar

The same screen has a third tab — `Dashboard → Students → Timetable` → **Academic Events** — for everything that is *not* a lesson: exams, holidays, result days, meetings and deadlines.

**Add event** → Title, Date, optional **End date** (or tick **All day**), Category (Exam, Holiday, Event, Deadline, Meeting, Other) → **Save**.

| Setting | Effect |
| --- | --- |
| **Target audience** | Everyone, specific classrooms, or teachers only |
| **Classrooms** | limit it to the classes it concerns |
| **Show on public website** | publish it on the institute's site |

Students and parents see the same calendar under their **Timetable → Academic Events** tab, so nothing needs to be sent separately.

## Troubleshooting

| Problem | Fix |
| --- | --- |
| Teacher missing | Add them first — [Teachers guide](/en/docs/school-operations/add-teachers-and-permissions) |
| Subject missing | Assign it to the classroom (step 3) |
| Conflict warning | Move one of the two clashing periods |
| Event not visible | Tick **Show on public website** and pick the right audience |
