## 1. Set salary structures

`Dashboard → Teachers` → open a teacher → **Salary** tab. Enter:

| Field | Value |
| --- | --- |
| Basic / Gross | headline monthly salary |
| Allowances | house rent, transport… |
| Deductions | provident fund, tax… |
| Pay mode | how they are paid |

Save, then repeat (or bulk-apply by designation).

---

## 2. Run monthly payroll

1. `Dashboard → Teachers → Salary` → choose the **month**.
2. eEdu pulls each person's **attendance** (unpaid leave, overtime) from the register/device.
3. Adjust any line (bonus, fine, advance recovery).
4. Click **Pay** (single or **Bulk Pay**).

> [!WARNING]
> Payroll is a money action. Double-check the month and adjustments before **Bulk Pay**.

---

## 3. Payslips & history

- Staff download their own payslip from **My Space → My Salary**.
- Admins use **`Teachers → Salary → Payment History`** to look up and re-print any payment.

---

## 4. Loans & advances

`Dashboard → Teachers → Salary → Loan Management` → add a loan (amount, installments, start month). eEdu deducts the installment automatically until repaid; staff track it in **My Space → My Loans**.

---

## 5. Leave quota

`Dashboard → Teachers → Leave Quota` → set each person's yearly entitlement. Approved leave draws from this; anything beyond the paid quota is unpaid. See [Teachers & Permissions](/docs/school-operations/add-teachers-and-permissions).

## Troubleshooting

| Problem | Fix |
| --- | --- |
| Salary wrong | Check unpaid leave and manual deductions |
| No payslip for staff | Month not marked paid, or no My Space access |
| Loan not deducting | Loan inactive or start month not reached |
