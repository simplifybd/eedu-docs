Teachers do not need admin access for their own records. **My Space** is their self-service area, and leave plus performance reviews run through it.

---

## 1. My Space (teacher self-service)

`Dashboard → My Space` — one page, eleven tabs:

| Tab                                             | What a teacher finds                             |
| ----------------------------------------------- | ------------------------------------------------ |
| **Overview**                                    | Today's duties and a summary of everything below |
| **Attendance**                                  | Their own attendance record                      |
| **Leave**                                       | Balance, history and **Apply for Leave**         |
| **Salary**                                      | Monthly payslips with **Download Payslip**       |
| **Loans**                                       | Advances taken and repayment status              |
| **Timetable**                                   | Their weekly periods                             |
| **Classes / Students / Homework / Exam Duties** | What they teach and what they have set           |
| **Performance**                                 | Their approved review, read-only                 |

> [!NOTE]
> Use the **tabs on this page**. A teacher with no linked teacher profile sees _No teacher profile_ — an admin must link the account first in [Add Teachers & Permissions](/en/docs/school-operations/add-teachers-and-permissions).

---

## 2. Request leave (teacher)

In `Dashboard → My Space → Leave` → **Apply for Leave**:

1. **Type** — Casual, Sick, Earned, Unpaid or Special.
2. **From** and **To** — the day count updates as you change them.
3. **Reason** — required.
4. **Submit**. Pending requests can be withdrawn with **Cancel**.

The request moves to the approval queue below.

---

## 3. Approve or reject leave (admin/owner)

`Dashboard → Teachers → Leave Requests` → tabs **All / Pending / Approved / Rejected**:

- Open a request, read the reason and dates, then **Approve** or **Reject** (a note can be attached).
- Each row shows the period, reason and whether it is **Paid** or **Unpaid**.
- **Import** allows bulk-submitting leave from a spreadsheet for a batch of teachers.

Approved leave updates the teacher's balance automatically.

---

## 4. Set leave quotas

`Dashboard → Teachers → Leave Quota` → **Set quotas** → teacher, leave type, **Entitled days** → save.

The table shows **Entitled / Used / Remaining** per teacher per type (Casual, Sick, Earned, Unpaid, Special), so balances are visible before anyone applies. Set them at the start of the year.

---

## 5. Performance reviews

`Dashboard → Teachers → Performance` → **Add appraisal**:

| Field                                        | Notes                                                                                                          |
| -------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| Teacher, Year, Period                        | who and when                                                                                                   |
| Rating                                       | Excellent / Good / Average / Poor — this **suggests a score** (90 / 75 / 55 / 30); override it 0–100 if needed |
| Strengths, Areas to improve, Goals, Comments | the written review                                                                                             |

Status runs **Draft → Submit → Approve**. Only an approved review is visible to the teacher, read-only under _My Space → Performance_.

Appraisals are created and approved by the institute owner or an admin with **Performance** permission.

## Troubleshooting

| Problem                   | Fix                                                                                                                      |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| “No teacher profile”      | Link the staff account to a teacher record                                                                               |
| Leave button does nothing | Missing **Leave** permission — see [Add Teachers & Permissions](/en/docs/school-operations/add-teachers-and-permissions) |
| Balance wrong             | Check [Leave Quota](#4-set-leave-quotas) — entitled days may be unset                                                    |
| Performance tab empty     | The review is still in **Draft** — it appears once approved                                                              |
