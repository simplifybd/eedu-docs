## 1. Create homework

`Dashboard → Students → Homework` → **Add Homework**:

| Field | Value |
| --- | --- |
| **Title** | e.g. `Algebra exercise 4.2` |
| **Classroom** | the class that must do it |
| **Subject** | which subject |
| **Description** | the instruction students see |
| **Due date** | the deadline |
| **Attachment** | optional worksheet / PDF |

Save/publish — it appears instantly in the student and parent portals.

---

## 2. Track submissions

Open a homework to see each student as **Submitted** or **Pending** (with time). Click a student to view or download their upload.

---

## 3. Review & grade

Open a submission → add a **mark** and optional **feedback** → save.

---

## 4. What families see

- **Student:** `Academics → Homework` — description, due date, attachments, and upload their answer.
- **Parent:** the same list per child, to follow up at home.

Full walkthrough for families: [Student & Parent Portal](/docs/student-and-parent-portal).

## Troubleshooting

| Problem | Fix |
| --- | --- |
| Not visible | Save/publish, and check the active classroom |
| Can't upload | Portal access missing, or the due date passed |
| Wrong subject | Add the subject to the class first |
