---

"Punched but shows absent" — follow the sections in order.

---

## 1. Did the punch reach eEdu?

`Dashboard → Students → Attendance → Settings → Devices` → open the device's **Punch Logs** (filter today).

| You see | Meaning | Next |
| --- | --- | --- |
| Punch listed | eEdu received it | §2 |
| Punch but **Error** | No person matched | §4 |
| Nothing | Never arrived | §5 |

---

## 2. Punch arrived but the register looks wrong

- **Check the view** — right **classroom**, **shift** and **date**? The register only counts the class's day.
- **"Late", not "Present"** — a punch after the late cut-off (`Attendance → Settings`) is still attendance.
- **Today isn't final** — the automatic absent-check never marks today early.

---

## 3. Half-empty day

1. Students must be **enrolled** in the class for the active year.
2. The device's **target group** must include students.
3. In **period-wise** mode, only students with a period that day appear.

---

## 4. Punches show "Error"

The device user ID doesn't match anyone: note the ID, compare with the student's admission no. / teacher's employee ID, then fix the mapping or re-enroll. Errors never create fake absences. See [User ID mapping](/docs/hardware-guide/user-id-mapping).

---

## 5. Nothing arrived (device side)

Check push mode, server `api.eedu.bd` / port 443, secret key, internet, and the clock (`Asia/Dhaka`). Full walkthrough: [Device offline & sync](/docs/hardware-guide/offline-and-sync-troubleshooting). After the network returns, wait a few minutes — the device buffers and re-sends.

---

## 6. Repair a past day

Open that day's register and mark individuals (within the back-date limit, usually 7 days). You can't mark a future date. Don't mark *today* as a repair — a later correct punch upgrades it automatically.

---

## Quick decision table

| Symptom | Do first |
| --- | --- |
| Nothing in Punch Logs | Device guide (network/mode/key/clock) |
| Punch here, register empty | Wrong class/shift/date |
| "Late" not "Present" | Late-cutoff settings |
| Error status | User ID mapping |
| Absent looks wrong | Enrollment / academic year / approved leave |
