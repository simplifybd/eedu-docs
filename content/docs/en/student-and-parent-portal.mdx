Every student and guardian gets their own login. They sign in at the school address (e.g. `yourschool.eedu.bd`) with the email/phone and password the school provided.

---

## Student portal

| Menu | Shows |
| --- | --- |
| **Dashboard** | upcoming homework, notices, summary |
| **Academics → Attendance** | own attendance record + calendar |
| **Academics → Timetable** | class and exam routine |
| **Academics → Homework** | assignments, attachments, submission |
| **Academics → Results** | marksheets and report cards |
| **Finance → Fees** | fee statement and **Pay Online** |
| **Finance → Payment History** | past receipts |
| **Communication** | notices, announcements, notifications |
| **Communication → Leave Request** | apply for leave, track status |
| **Account** | profile and health records |

---

## Parent portal

A guardian follows **one or more children** from a single login. Use the **child switcher** at the top to change the selected child.

| Menu | Shows |
| --- | --- |
| **Dashboard** | the selected child's overview |
| **Academics** | attendance, timetable, homework, results |
| **Finance** | fees (**Pay Online**) and payment history |
| **Communication** | notices, announcements, notifications |
| **Communication → Leave Request** | apply for leave for the child |

---

## Paying fees online

1. **Finance → Fees** → open the unpaid month.
2. **Pay Online** → choose a method (bKash / Nagad / card / bank).
3. Complete payment on the gateway page.
4. The fee turns **Paid** and a **QR receipt** is created automatically.

> [!TIP]
> If a payment is interrupted, don't pay twice — check **Payment History** after a few minutes. See [payment issues](/docs/troubleshooting/payment-and-receipt-issues).

---

## Downloads

- **Report cards:** `Academics → Results` for each published exam term.
- **ID cards / certificates:** from the account area, where the school enabled them.

---

## Leave requests

`Communication → Leave Request` → choose dates, add a reason, submit. The teacher/office approves or rejects it and the status updates in the same list.

## Troubleshooting

| Problem | Fix |
| --- | --- |
| Can't see a child | Ask the school to link the guardian to the student |
| Results/routine missing | Not published yet |
| No **Pay Online** | School hasn't enabled online payment |
| Wrong name/class | Contact the school office |
