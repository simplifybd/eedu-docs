প্রত্যেক শিক্ষার্থী ও অভিভাবক নিজস্ব লগইন পান। স্কুলের দেওয়া ইমেইল/ফোন ও পাসওয়ার্ড দিয়ে স্কুলের ঠিকানায় (যেমন `yourschool.eedu.bd`) সাইন ইন করেন।

---

## শিক্ষার্থী পোর্টাল

| মেনু | যা দেখায় |
| --- | --- |
| **Dashboard** | আসন্ন হোমওয়ার্ক, নোটিশ, সারসংক্ষেপ |
| **Academics → Attendance** | নিজের উপস্থিতি ও ক্যালেন্ডার |
| **Academics → Timetable** | ক্লাস ও পরীক্ষার রুটিন |
| **Academics → Homework** | অ্যাসাইনমেন্ট, সংযুক্তি, জমা |
| **Academics → Results** | মার্কশিট ও রিপোর্ট কার্ড |
| **Finance → Fees** | ফি বিবরণী ও **Pay Online** |
| **Finance → Payment History** | পূর্বের রসিদ |
| **Communication** | নোটিশ, ঘোষণা, নোটিফিকেশন |
| **Communication → Leave Request** | ছুটির আবেদন ও স্ট্যাটাস |
| **Account** | প্রোফাইল ও স্বাস্থ্য রেকর্ড |

---

## অভিভাবক পোর্টাল

একজন অভিভাবক এক লগইন থেকেই **এক বা একাধিক সন্তান** দেখেন। শীর্ষের **child switcher** দিয়ে নির্বাচিত সন্তান বদলান।

| মেনু | যা দেখায় |
| --- | --- |
| **Dashboard** | নির্বাচিত সন্তানের সারসংক্ষেপ |
| **Academics** | উপস্থিতি, রুটিন, হোমওয়ার্ক, ফলাফল |
| **Finance** | ফি (**Pay Online**) ও পেমেন্ট ইতিহাস |
| **Communication** | নোটিশ, ঘোষণা, নোটিফিকেশন |
| **Communication → Leave Request** | সন্তানের জন্য ছুটির আবেদন |

---

## অনলাইনে ফি পরিশোধ

1. **Finance → Fees** → unpaid মাস খুলুন।
2. **Pay Online** → মাধ্যম বাছুন (bKash / Nagad / কার্ড / ব্যাংক)।
3. গেটওয়ে পেজে পেমেন্ট সম্পন্ন করুন।
4. ফি **Paid** হবে ও স্বয়ংক্রিয়ভাবে **QR রসিদ** তৈরি হবে।

> [!TIP]
> পেমেন্ট বিঘ্নিত হলে দ্বিতীয়বার দেবেন না — কয়েক মিনিট পর **Payment History** দেখুন। দেখুন [পেমেন্ট সমস্যা](/bn/docs/troubleshooting/payment-and-receipt-issues)।

---

## ডাউনলোড

- **রিপোর্ট কার্ড:** প্রকাশিত প্রতিটি পরীক্ষার জন্য `Academics → Results`।
- **আইডি কার্ড / সার্টিফিকেট:** অ্যাকাউন্ট অংশে, যেখানে স্কুল চালু করেছে।

---

## ছুটির আবেদন

`Communication → Leave Request` → তারিখ ও কারণ লিখে জমা দিন। শিক্ষক/অফিস অনুমোদন বা বাতিল করেন এবং একই তালিকায় স্ট্যাটাস হালনাগাদ হয়।

## সমস্যা সমাধান

| সমস্যা | সমাধান |
| --- | --- |
| সন্তান দেখা যাচ্ছে না | শিক্ষার্থীর সাথে অভিভাবক লিংক করতে স্কুলকে বলুন |
| ফলাফল/রুটিন নেই | এখনও প্রকাশিত হয়নি |
| **Pay Online** নেই | স্কুল অনলাইন পেমেন্ট চালু করেনি |
| ভুল নাম/ক্লাস | স্কুল অফিসে যোগাযোগ করুন |
