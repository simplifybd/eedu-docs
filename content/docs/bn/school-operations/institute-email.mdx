---

প্রাতিষ্ঠানিক ইমেইল ফিচারটি প্রো প্ল্যানে পাওয়া যায়। এর মাধ্যমে আপনার নিজের ডোমেইন থেকে (যেমন `principal@example.edu.bd`) প্ল্যাটফর্মের পরিচালিত মেইল সার্ভার (`mail.eedu.bd`) ব্যবহার করে ইমেইল পাঠানো ও গ্রহণ করা যায়।

---

## ১. শুরুর আগে যা লাগবে

| প্রয়োজনীয়তা                        | কারণ                                           |
| ------------------------------------ | ---------------------------------------------- |
| প্রো প্ল্যান (অথবা সক্রিয় ট্রায়াল) | ইমেইল শুধু প্রো প্ল্যানের ফিচার                |
| আপনার নিজের একটি ডোমেইন              | যেমন `example.edu.bd`                          |
| ডোমেইনের DNS সেটিংসে প্রবেশাধিকার    | রেজিস্ট্রার বা DNS হোস্টে (Cloudflare ইত্যাদি) |

---

## ২. মেইল ডোমেইন যুক্ত করুন

`ড্যাশবোর্ড → যোগাযোগ → ইমেইল`

1. আপনার ডোমেইনটি লিখে **Check availability** চাপুন।
2. **Connect domain** চাপুন। eEdu মেইল প্ল্যাটফর্মে ডোমেইনটি প্রস্তুত করে এবং একটি DKIM স্বাক্ষর কী তৈরি করে।

ডোমেইনটি এখন **PENDING DNS** স্ট্যাটাস এবং যোগ করার জন্য DNS রেকর্ডের তালিকাসহ দেখাবে।

---

## ৩. DNS রেকর্ড যোগ করুন

আপনার ডোমেইন রেজিস্ট্রারে ইমেইল পেজে দেখানো রেকর্ডগুলো হুবহু যোগ করুন:

| টাইপ          | হোস্ট             | মান                                                 |
| ------------- | ----------------- | --------------------------------------------------- |
| `MX`          | `@`               | `mail.eedu.bd` (প্রায়োরিটি ১০)                     |
| `TXT` (SPF)   | `@`               | `v=spf1 mx a:mail.eedu.bd ~all`                     |
| `TXT` (DKIM)  | `dkim._domainkey` | পেজে দেখানো DKIM মান                                |
| `TXT` (DMARC) | `_dmarc`          | `v=DMARC1; p=quarantine; pct=100; adkim=r; aspf=r;` |
| `CNAME`       | `autodiscover`    | `mail.eedu.bd`                                      |
| `CNAME`       | `autoconfig`      | `mail.eedu.bd`                                      |

এরপর **Verify DNS** চাপুন। প্রতিটি রেকর্ড সামনে সবুজ/লাল চিহ্ন দেখাবে। MX, SPF, DKIM, DMARC — চারটি মূল রেকর্ড যাচাই হলে ডোমেইন **ACTIVE** হয়ে যাবে।

<Callout type="warn">
  DNS পরিবর্তন প্রকাশ হতে কয়েক মিনিট লাগতে পারে। পেন্ডিং ডোমেইনগুলো eEdu প্রতি
  ঘণ্টায় একবার স্বয়ংক্রিয়ভাবে যাচাই করে।
</Callout>

---

## ৪. মেইলবক্স তৈরি করুন

ডোমেইন **ACTIVE** হওয়ার পর **New mailbox** চাপুন:

| ঘর           | উদাহরণ                                   |
| ------------ | ---------------------------------------- |
| ইমেইল ঠিকানা | `principal` → `principal@example.edu.bd` |
| ডিসপ্লে নাম  | `Principal Office`                       |
| স্টোরেজ কোটা | ১০০–১০২৪০ MB (প্ল্যান অনুযায়ী)          |

<Callout type="warn">
  মেইলবক্সের পাসওয়ার্ড তৈরির সাথে সাথে **একবার**ই দেখানো হয় এবং eEdu কখনো
  সংরক্ষণ করে না। ডায়ালগ বন্ধ করার আগে কপি করে রাখুন।
</Callout>

মেইলবক্স তালিকায় লাইভ ব্যবহারের পরিমাণ দেখা যায়; নাম, কোটা ও সক্রিয়তা সম্পাদনা বা মুছে ফেলা যায়। `admin`, `postmaster`, `noreply` ইত্যাদি নাম সংরক্ষিত।

প্রতিটি মেইলবক্স সারিতে অতিরিক্ত অ্যাকশন আছে:

| অ্যাকশন                        | কী করে                                                                                                                            |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| **Change password** (কি আইকন)  | নতুন পাসওয়ার্ড সেট করুন বা শক্তিশালী পাসওয়ার্ড তৈরি করুন (একবার দেখানো হয়)। চাইলে পরবর্তী লগইনে পরিবর্তন বাধ্যতামূলক করা যায়। |
| **App passwords** (শিল্ড আইকন) | ফোন/Outlook ইত্যাদি অ্যাপের জন্য আলাদা অ্যাপ পাসওয়ার্ড তৈরি করুন, যাতে মূল পাসওয়ার্ড গোপন থাকে। প্রতি মেইলবক্সে সর্বোচ্চ ১০টি।  |

---

## ৫. অ্যালিয়াস (Aliases)

মেইলবক্স টেবিলের নিচের `Aliases` সেকশনে বিদ্যমান মেইলবক্সে মেইল পৌঁছানোর জন্য অতিরিক্ত ঠিকানা তৈরি করুন:

| ঘর                | উদাহরণ                                                               |
| ----------------- | -------------------------------------------------------------------- |
| অ্যালিয়াস ঠিকানা | `info` → `info@example.edu.bd`                                       |
| গন্তব্য           | `principal@example.edu.bd, admissions@example.edu.bd` (সর্বোচ্চ ৫টি) |
| মন্তব্য           | "Front office inbox" (ঐচ্ছিক)                                        |

বিভাগীয় ঠিকানার জন্য (`admissions@`, `accounts@`) আলাদা মেইলবক্স না বানিয়ে অ্যালিয়াস ব্যবহার করুন।

---

## ৬. ফরওয়ার্ডার (Forwarders)

`Forwarders` সেকশন — কোনো মেইলবক্সের সব মেইল স্বয়ংক্রিয়ভাবে অন্য ঠিকানায় পাঠিয়ে দেয় (যেমন `principal@example.edu.bd` → প্রধান শিক্ষকের ব্যক্তিগত ইনবক্স)। প্রতি মেইলবক্সে একটি ফরওয়ার্ডার; গন্তব্য বদলাতে আগে মুছে ফেলুন।

---

## ৭. ইমেইল ব্যবহার করুন

- **ওয়েবমেইল**: `https://mail.eedu.bd` খুলে সম্পূর্ণ ইমেইল ঠিকানা ও তৈরি করা পাসওয়ার্ড দিয়ে সাইন ইন করুন।
- **ইমেইল অ্যাপ** (Outlook, Thunderbird, ফোন মেইল):

| সেটিংস           | মান                                                   |
| ---------------- | ----------------------------------------------------- |
| ইউজারনেম         | সম্পূর্ণ ইমেইল ঠিকানা                                 |
| ইনকামিং (IMAP)   | `mail.eedu.bd`, পোর্ট `993`, SSL/TLS                  |
| আউটগোয়িং (SMTP) | `mail.eedu.bd`, পোর্ট `465` (SSL) বা `587` (STARTTLS) |

## ৮. প্ল্যান সীমা

| প্ল্যান | মেইলবক্স                         | ডোমেইন স্টোরেজ                     |
| ------- | -------------------------------- | ---------------------------------- |
| ফ্রি    | — (ফিচারটি বন্ধ)                 | —                                  |
| প্রো    | প্ল্যান অনুযায়ী কোটা (যেমন ১০০) | প্ল্যান অনুযায়ী কোটা (যেমন ১০ GB) |

ব্যক্তিগত মেইলবক্সের কোটা ডোমেইনের মোট স্টোরেজের মধ্য থেকে কাটা হয়। অ্যাডমিন প্ল্যান অনুযায়ে **Admin → Plans** থেকে কোটা সম্পাদনা করতে পারেন।

## ৯. সমস্যা সমাধান

| সমস্যা                                | যা দেখবেন                                                                                             |
| ------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| স্ট্যাটাস **PENDING DNS**-ই থেকে যায় | MX/SPF/DKIM/DMARC এর এক বা একাধিক রেকর্ড নেই বা ছড়িয়ে পড়তে সময় নিচ্ছে — আবার **Verify DNS** চাপুন |
| "Domain already in use"               | ডোমেইনটি অন্য কোনো ইনস্টিটিউটের সাথে যুক্ত বা মেইল প্ল্যাটফর্মে আগে থেকেই আছে                         |
| "Mailbox limit reached"               | অব্যবহৃত মেইলবক্স মুছুন বা প্ল্যান আপগ্রেড করুন                                                       |
| "Storage quota fully allocated"       | বিদ্যমান মেইলবক্সের কোটা কমিয়ে দিন                                                                   |
| ডোমেইন রিমুভ করা                      | **Remove domain** সব মেইলবক্স ও তাদের মেইল স্থায়ীভাবে মুছে ফেলে                                      |

সুপার-অ্যাডমিনরা `ড্যাশবোর্ড → অ্যাডমিন → অপারেশনস → Email Control` থেকে সব ইনস্টিটিউটের ডোমেইন পর্যবেক্ষণ করতে পারেন।
