## ১. ক্যাটালগে বই যোগ করুন

`ড্যাশবোর্ড → শিক্ষার্থী → লাইব্রেরি → বই` → **বই যোগ করুন** → শিরোনাম, লেখক, ISBN, বিভাগ, কপি, জরিমানা/দিন, ধার দিন → সংরক্ষণ। বাল্কের জন্য **স্প্রেডশিট ইম্পোর্ট** ব্যবহার করুন।

প্রতিটি বইয়ের উপলব্ধ ও মোট কপি স্বয়ংক্রিয়ভাবে ট্র্যাক হয়।

---

## ২. বই ইস্যু করুন

1. `ড্যাশবোর্ড → শিক্ষার্থী → লাইব্রেরি → বই`।
2. বইয়ের **অ্যাকশন → ইস্যু** (শুধু স্টকে কপি থাকলে)।
3. **শিক্ষার্থী** নির্বাচন করুন এবং **নির্ধারিত তারিখ** সেট করুন (ডিফল্ট ধার দিন)।
4. সংরক্ষণ — কপি ইস্যুকৃত হয়ে যায়।

---

## ৩. ফেরত বা নিখোঁজ চিহ্নিত

`ড্যাশবোর্ড → শিক্ষার্থী → লাইব্রেরি → ইস্যু`:

- **ফেরত** — ইস্যু ফেরত, বিলম্ব জরিমানা হিসাব, কপি মুক্ত।
- **নিখোঁজ** — ইস্যু নিখোঁজ চিহ্নিত এবং নিখোঁজ বইয়ের জরিমানা।

---

## ৪. রিজার্ভেশন

বই স্টকে না থাকলে, **অ্যাকশন → রিজার্ভ** খুলে শিক্ষার্থী নির্বাচন করুন। শিক্ষার্থী সারিতে যোগ হয়।

- কপি ফেরত হলে প্রথম পেন্ডিং রিজার্ভেশন **প্রস্তুত** হয় (৩ দিন তোলার সময়)।
- **বাতিল** রিজার্ভেশন সরায়; বই ক্যাটালগে থাকে।

`ড্যাশবোর্ড → শিক্ষার্থী → লাইব্রেরি → রিজার্ভেশন` সারি ও স্ট্যাটাস দেখায়।

| জরিমানা ভুল       | বইয়ের ধার দিন/জরিমানা প্রতি দিন ঠিক করুন |
| রিজার্ভেশন আটকে   | বাতিল করে নতুন করুন                       |
