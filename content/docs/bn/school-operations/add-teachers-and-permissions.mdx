## ১. শিক্ষকের রেকর্ড যোগ করুন

`ড্যাশবোর্ড → শিক্ষক` → **শিক্ষক যোগ করুন**:

| ক্ষেত্র | কী দিতে হবে |
| --- | --- |
| **সম্পূর্ণ নাম** | রেজিস্টার ও পে-স্লিপে যেভাবে দেখাবে |
| **পদবি / বিভাগ** | যেমন সহকারী শিক্ষক · বিজ্ঞান |
| **ফোন / ইমেইল** | ড্যাশবোর্ড অ্যাক্সেসের জন্য ইমেইল দরকার |
| **এমপ্লয়ি আইডি** | খালি রাখুন — eEdu তৈরি করবে |
| **যোগদানের তারিখ** | প্রথম কর্মদিবস |
| **ওয়েবসাইটে দেখান** | পাবলিক "আমাদের শিক্ষক" পৃষ্ঠায় দেখাবে |
| **ড্যাশবোর্ড অ্যাক্সেস দিন** | লগইন দেবে (ধাপ ২) |

Save করুন। **এমপ্লয়ি আইডি** (যেমন `000017`) বায়োমেট্রিক ডিভাইসেও ব্যবহৃত হয় — দেখুন [ইউজার আইডি ম্যাপিং](/bn/docs/hardware-guide/user-id-mapping)।

## ২. লগইন দিন

eEdu নিজেই সঠিক পথ বেছে নেয়:

- **আগে eEdu অ্যাকাউন্ট থাকলে** → সঙ্গে সঙ্গে অ্যাক্সেস।
- **নতুন হলে** → eEdu ইমেইলে একটি **আমন্ত্রণ লিংক** পাঠায়।

দিতে: শিক্ষক খুলে **Invite / Dashboard access** → রোল বাছুন → save। লিংকের মেয়াদ শেষ হলে আবার পাঠান।

---

## ৩. অনুমতি ঠিক করুন

`ড্যাশবোর্ড → অ্যাকাউন্ট → Team Members` (শুধু ওনার)। প্রতিটি ফিচার তিন স্তরে:

| স্তর | অর্থ |
| --- | --- |
| **Write** | দেখা **ও** পরিবর্তন |
| **Read** | শুধু দেখা |
| **Off** | মেনুতে লুকানো |

ফিচার টিক করুন (**উপস্থিতি, ফি, ফলাফল, শিক্ষার্থী, রিপোর্ট**…), চাইলে **নির্দিষ্ট ক্লাসরুমে** সীমাবদ্ধ করুন, save করুন।

> [!TIP]
> নতুন শিক্ষকদের **Read** দিয়ে শুরু করুন। বেশিরভাগের দরকার: উপস্থিতি, ফলাফল, হোমওয়ার্ক ও নিজের ছুটি।

## ৪. মাই স্পেস (শিক্ষক যা দেখেন)

প্রত্যেক শিক্ষক নিজের **My Space** পান: প্রোফাইল, উপস্থিতি ও ক্যালেন্ডার, ছুটি ও স্ট্যাটাস, পে-স্লিপ, রুটিন/ক্লাস। সদস্যরা অন্য শিক্ষকের বেতন কখনো দেখতে পারেন না।

---

## ৫. অ্যাক্সেস সরানো

শিক্ষক খুলে **Archive** (রেকর্ড থাকবে, লগইন যাবে)। ইতিহাস রিপোর্টে থাকে। ফিরে এলে শুধু HR রেকর্ড আসে — আবার অ্যাক্সেস দিতে হবে।

পরের গাইড: **[ক্লাস রুটিন ও টাইমটেবল](/bn/docs/school-operations/class-routine-and-timetable)**।
