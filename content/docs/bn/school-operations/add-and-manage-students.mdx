শিক্ষার্থী রেজিস্টারই উপস্থিতি, ফি, পরীক্ষা ও দুই পোর্টালের উৎস। একবার, সঠিকভাবে যোগ করুন — বাকি সবকিছু এই রেকর্ড থেকেই আসে।

---

## ১. শিক্ষার্থী যোগ করুন

`ড্যাশবোর্ড → শিক্ষার্থী → Students` → **Add student**। ফর্মটি ছয় ভাগে ভাগ; তারকা চিহ্নিত ঘরগুলোই আবশ্যক।

| অংশ | যা লিখবেন |
| --- | --- |
| **Basic information** | পুরো নাম, লিঙ্গ, রক্তের গ্রুপ, জন্মতারিখ; NID ও ছবি থাকলে |
| **Guardian / Parent information** | অন্তত একজন অভিভাবক — ধাপ ২ দেখুন |
| **Address & additional details** | বিভাগ / জেলা / উপজেলা, ঠিকানা, আগের স্কুল, ট্রান্সফার সার্টিফিকেট নম্বর |
| **Emergency contact** | নাম, ফোন, সম্পর্ক |
| **Additional notes** | উন্মুক্ত লেখা, সর্বোচ্চ ৫০০ অক্ষর |
| **Documents** | সর্বোচ্চ ২০টি লিংক (জন্মসনদ, ছবি, ফর্ম) |

**Save changes** চাপলে রেকর্ড তৈরি হবে।

> [!TIP]
> শিক্ষার্থী বা অভিভাবকের **ফোন নম্বর দিলে সেই ব্যক্তির লগইন অ্যাকাউন্ট স্বয়ংক্রিয়ভাবে তৈরি হয়**। এখনো লগইন দিতে না চাইলে খালি রাখুন।

---

## ২. অভিভাবক যুক্ত করুন

প্রতি শিক্ষার্থীর **অন্তত একজন অভিভাবক** লাগে। ফর্মে **Add guardian** চেপে আরও অভিভাবক যোগ করুন (বাবা-মা, অভিভাবক ও দাদা-দিদা)।

- **Name**, **Phone** ও **Relation** পূরণ করুন।
- স্কুল যার সাথে যোগাযোগ করে — **Primary guardian** তার ওপর টিক দিন; একজনই প্রাইমারি হতে পারে।
- **Guardian phone** দিয়েই প্যারেন্ট লগইন তৈরি হয়, তাই পরিবার সত্যিই ধরে রাখে এমন নম্বর দিন।

পরে প্রোফাইল → **Guardians** ট্যাব থেকে সম্পাদনা করা যায় (**Add guardian** / **Edit** / **Remove**)।

---

## ৩. রেজিস্টার খোঁজ ও রক্ষণাবেক্ষণ

`ড্যাশবোর্ড → শিক্ষার্থী → Students`:

- নাম বা ভর্তি নম্বর দিয়ে খুঁজুন।
- **স্ট্যাটাস** (Active, Inactive, Suspended, Graduated, Dropout, Archived), লিঙ্গ বা ক্লাস দিয়ে ফিল্টার করুন।
- সারি সিলেক্ট করে বাল্ক **Edit / Delete / Archive / Restore**।
- প্রতি সারির মেনুতে **View profile**, **Edit student**, **Send SMS**, **Archive**।

**Archive** ইতিহাস না ভেঙে শিক্ষার্থীকে লুকায় — Delete-এর চেয়ে এটাই নিরাপদ। **Delete** শুধু যেখানে নিরাপদ, সেখানেই দেওয়া হয়।

---

## ৪. ক্লাসে ভর্তি ও ট্রান্সফার

`ড্যাশবোর্ড → শিক্ষার্থী → Enrollments`:

1. **Enroll student** → শিক্ষার্থী, ক্লাস ও একাডেমিক বছর বেছে Save। শিক্ষার্থী এখন ওই ক্লাসের উপস্থিতি, ফি ও ফলাফলে আসবে।
2. বছরের মাঝখানে ক্লাস বদলাতে সারি সিলেক্ট → **Transfer student** → নতুন ক্লাস বাছুন। পুরনো রেকর্ড আগের ক্লাসেই থাকে।
3. পুরো ব্যাচের জন্য **Import spreadsheet** / **Export CSV**।

> [!NOTE]
> উপস্থিতি, পরীক্ষার নম্বর ও ফি — সবই **enrollment**-এর সাথে যুক্ত, শুধু শিক্ষার্থীর সাথে নয়। Enrollment ছাড়া শিক্ষার্থী দৈনিক রেজিস্টারে কোথাও আসবে না।

## ৫. ID কার্ড, ট্রান্সফার সার্টিফিকেট ও স্বাস্থ্যরেকর্ড

যেকোনো শিক্ষার্থী খুলুন (`ড্যাশবোর্ড → শিক্ষার্থী → Students` → **View profile**)। হেডারে আছে:

- **Download ID card** — প্রিন্টযোগ্য PDF।
- **Transfer certificate** — শিক্ষার্থী চলে গেলে TC দিন।
- **Collect payment** — সরাসরি ফি আদায়ে।
- **Archive / Restore / Delete**।

ট্যাব: **Personal**, **Academic**, **Fees**, **Attendance**, **Guardians**, **Health**।

**Health** ট্যাবে চেকআপ, টিকা, ওষুধ, অ্যালার্জি ও আঘাত — তীব্রতা (severity) সহ রাখা হয়। ফিল্ড ট্রিপ বা জরুরি অবস্থায় কাজে লাগে।

## ৬. বাল্ক ইমপোর্ট ও এক্সপোর্ট

eEdu-র বেশিরভাগ তালিকাতে একই প্রবাহ আছে, তাই একবার শিখলেই শিক্ষার্থী, শিক্ষক, enrollment, ক্লাস, বিষয়, হোমওয়ার্ক, ছুটি ও লাইব্রেরির বই — সব কবে হবে:

1. **Import CSV** / **Import spreadsheet** চাপুন।
2. **Download template** নামিয়ে পূরণ করে **Upload a spreadsheet** (Excel বা CSV)।
3. **Column mapping** — কলামগুলো eEdu ঘরের সাথে মিলিয়ে (**Ignore this column** দিয়ে বাদও দেওয়া যায়)।
4. সংখ্যা দেখুন — *rows detected*, *valid*, *need attention* — প্রিভিউ করে কনফার্ম।
5. কিছু ব্যর্থ হলে **Download error report**-এ সারি ও কারণ পাওয়া যাবে।

একই টুলবারে **Export CSV** (বা **Export → Excel**) ব্যাকআপ ও অফলাইন হিসাবের জন্য আছে।

## সমস্যা সমাধান

| সমস্যা | সমাধান |
| --- | --- |
| Save করছে না | তারকা চিহ্নিত ঘর, বিশেষত অভিভাবক পূরণ করুন |
| শিক্ষার্থী ক্লাসে নেই | তার **enrollment** নেই — ধাপ ৪ করুন |
| অভিভাবক লগইন করতে পারছে না | গার্ডিয়ান ফোন অবশ্যই ইউনিক — মিলিয়ে দেখুন |
| পুরনো রেকর্ডে ভুল ক্লাস | এটাই স্বাভাবিক — ট্রান্সফারে ইতিহাস যায় না |
| Confirm-এ import ব্যর্থ | error report-এর সারি ঠিক করে আবার আপলোড করুন |
