নিজের রেকর্ড দেখতে শিক্ষকদের অ্যাডমিন অ্যাক্সেস লাগে না। **মাই স্পেস**-ই তাদের সেল্‌ফ-সার্ভিস এলাকা, আর ছুটি ও কর্মদক্ষতা মূল্যায়ন এখান দিয়েই চলে।

---

## ১. মাই স্পেস (শিক্ষকের সেল্‌ফ-সার্ভিস)

`ড্যাশবোর্ড → My Space` — একটি পেজ, এগারোটি ট্যাব:

| ট্যাব                                           | শিক্ষক যা পাবেন                           |
| ----------------------------------------------- | ----------------------------------------- |
| **Overview**                                    | আজকের দায়িত্ব ও নিচের সবকিছুর সারসংক্ষেপ |
| **Attendance**                                  | নিজের উপস্থিতির রেকর্ড                    |
| **Leave**                                       | ব্যালেন্স, ইতিহাস ও **Apply for Leave**   |
| **Salary**                                      | মাসিক পে-স্লিপ, **Download Payslip** সহ   |
| **Loans**                                       | নেওয়া অগ্রিম ও পরিশোধের অবস্থা           |
| **Timetable**                                   | নিজের সাপ্তাহিক পিরিয়ড                   |
| **Classes / Students / Homework / Exam Duties** | যা পড়ান ও যা দিয়েছেন                    |
| **Performance**                                 | অনুমোদিত মূল্যায়ন, শুধু পড়ার জন্য       |

> [!NOTE]
> **এই পেজের ট্যাবগুলোই** ব্যবহার করুন। শিক্ষক প্রোফাইল যুক্ত না থাকলে _No teacher profile_ দেখাবে — অ্যাডমিনকে আগেই [শিক্ষক যুক্ত করা ও অনুমতি](/bn/docs/school-operations/add-teachers-and-permissions)-তে অ্যাকাউন্ট যুক্ত করতে হবে।

---

## ২. ছুটির আবেদন (শিক্ষক)

`ড্যাশবোর্ড → My Space → Leave` → **Apply for Leave**:

1. **Type** — Casual, Sick, Earned, Unpaid বা Special।
2. **From** ও **To** — বদলালেই দিনের সংখ্যা হিসাব হয়।
3. **Reason** — আবশ্যক।
4. **Submit**। অপেক্ষমাণ আবেদন **Cancel** করে ফেলা যায়।

আবেদনটি নিচের অনুমোদন তালিকায় চলে যায়।

---

## ৩. ছুটি অনুমোদন বা প্রত্যাখ্যান (অ্যাডমিন/ওনার)

`ড্যাশবোর্ড → Teachers → Leave Requests` → **All / Pending / Approved / Rejected** ট্যাব:

- আবেদন খুলে কারণ ও তারিখ দেখে **Approve** বা **Reject** করুন (নোটও দেওয়া যায়)।
- প্রতি সারিতে সময়কাল, কারণ ও এটি **Paid** নাকি **Unpaid** দেখায়।
- **Import** দিয়ে একসাথে অনেক শিক্ষকের ছুটি স্প্রেডশিট থেকে জমা দেওয়া যায়।

অনুমোদিত হলে শিক্ষকের ব্যালেন্স নিজে থেকেই হ্রাস পায়।

---

## ৪. ছুটির কোটা সেট

`ড্যাশবোর্ড → Teachers → Leave Quota` → **Set quotas** → শিক্ষক, ছুটির ধরন, **Entitled days** → Save।

প্রতি শিক্ষক ও প্রতি ধরনে **Entitled / Used / Remaining** দেখায়, তাই আবেদনের আগেই ব্যালেন্স জানা যায়। বছরের শুরুতে সেট করে রাখুন।

---

## ৫. কর্মদক্ষতা মূল্যায়ন

`ড্যাশবোর্ড → Teachers → Performance` → **Add appraisal**:

| ঘর                                           | নোট                                                                                                               |
| -------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Teacher, Year, Period                        | কার, কবর                                                                                                          |
| Rating                                       | Excellent / Good / Average / Poor — এতে **স্কোর প্রস্তাব হয়** (৯০ / ৭৫ / ৫৫ / ৩০); দরকার হলে ০–১০০ পর্যন্ত বদলান |
| Strengths, Areas to improve, Goals, Comments | লিখিত মূল্যায়ন                                                                                                   |

স্ট্যাটাস চলে **Draft → Submit → Approve**। অনুমোদনের আগে মূল্যায়ন কারও দেখা যায় না; অনুমোদনের পর শিক্ষক _মাই স্পেস → Performance_-এ শুধু পড়তে পারেন।

অ্যাপ্রেইসাল প্রতিষ্ঠানের ওনার বা **Performance** অনুমতিসহ অ্যাডমিন তৈরি ও অনুমোদন করেন।

## সমস্যা সমাধান

| সমস্যা                  | সমাধান                                                                                                        |
| ----------------------- | ------------------------------------------------------------------------------------------------------------- |
| “No teacher profile”    | স্টাফ অ্যাকাউন্টকে শিক্ষক রেকর্ডে যুক্ত করুন                                                                  |
| ছুটির বোতাম কাজ করছে না | **Leave** অনুমতি নেই — দেখুন [শিক্ষক যুক্ত ও অনুমতি](/bn/docs/school-operations/add-teachers-and-permissions) |
| ব্যালেন্স ভুল           | **Set quotas** দেখুন (৪ নং ধাপ) — entitled days সেট না থাকতে পারে                                             |
| Performance ট্যাব খালি  | মূল্যায়ন এখনো **Draft**-এ — অনুমোদনের পর আসবে                                                                |

পরের গাইড: **[রিপোর্ট ও অ্যানালিটিক্স](/bn/docs/school-operations/reports-and-analytics)**।
