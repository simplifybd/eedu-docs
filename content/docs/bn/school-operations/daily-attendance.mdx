## ১. একবার নিয়ম ঠিক করুন

`ড্যাশবোর্ড → শিক্ষার্থী → উপস্থিতি` → **Settings**:

| সেটিং | নিয়ন্ত্রণ করে |
| --- | --- |
| Marking mode | একটি **দৈনিক** রেকর্ড, বা **পিরিয়ডভিত্তিক** |
| Late cut-off | কোন সময়ের পরে **Late** |
| সাপ্তাহিক ছুটি | যে দিন উপস্থিতি নেই |
| শিফট | সকাল / দিন / সন্ধ্যা |

শিফট থাকলে প্রতিটি ক্লাসে সঠিক **shift** বসান।

---

## ২. উপস্থিতি নিন

1. `ড্যাশবোর্ড → শিক্ষার্থী → উপস্থিতি` → **Mark Attendance**।
2. ক্লাসরুম, তারিখ ও (পিরিয়ডভিত্তিক হলে) পিরিয়ড বাছুন।
3. **Mark all present** চেপে শুধু ব্যতিক্রম বদলান: **Present / Late / Absent / Leave**।
4. Save করুন।

> [!TIP]
> ডিভাইস থাকলে পাঞ্চ রেজিস্টার ভরে দেয় — আপনি শুধু ব্যতিক্রম ঠিক করুন (পাঞ্চ ভুলে যাওয়া, অনুমোদিত ছুটি)।

---

## ৩. পর্যালোচনা ও এক্সপোর্ট

একই স্ক্রিন থেকে:

- প্রতি শিক্ষার্থীর **মাসিক ক্যালেন্ডার** (রঙে আলাদা)।
- **ক্লাস সারসংক্ষেপ** ও **low-attendance রিপোর্ট**।
- রেজিস্টার **CSV / PDF**-এ এক্সপোর্ট।

---

## ৪. অনুপস্থিতির সতর্কতা

`ড্যাশবোর্ড → শিক্ষার্থী → Absence Alerts` → **চ্যানেল** বাছুন (SMS / WhatsApp / ইন-অ্যাপ), কত দিন অনুপস্থিতিতে সতর্কতা যাবে ও বার্তা ঠিক করুন। এককালীন পাঠান বা নির্ধারিত সময়ে চলতে দিন।

> [!WARNING]
> সতর্কতা আপনার প্রতিষ্ঠানের SMS/WhatsApp ক্রেডিট থেকে যায় — আগে sender ID ও ব্যালেন্স দেখুন।
