## ১. ডিভাইস অনলাইন?

ডিভাইসে **COMM / Network** খুলে দেখুন IP আছে কি না।

- **IP নেই** → LAN কেবল / Wi-Fi পাসওয়ার্ড দেখে রিবুট করুন।
- **IP আছে কিন্তু ইন্টারনেট নেই** → স্কুলের অন্য ডিভাইসে যেকোনো ওয়েবসাইট খুলুন; না খুললে আগে ইন্টারনেট ঠিক করুন।

## ২. eEdu-র দিকে তাক করা আছে?

| সেটিং | হওয়া উচিত |
| --- | --- |
| Attendance mode | **Push / Cloud** |
| Server / Push URL | `https://api.eedu.bd/api/v1/devices/attendance/ingest` |
| Port | `443` |
| Secret key | eEdu-র সাথে মিল |

> [!NOTE]
> `ড্যাশবোর্ড → শিক্ষার্থী → উপস্থিতি → Settings → Devices`-এ push URL ও secret key আবার দেখুন। একটি অক্ষর ভুল হলেই সব পাঞ্চ থেমে যায়।

## ৩. সময় ঠিক আছে?

ভুল সময় = ভুল দিন/লেট স্ট্যাটাস।

1. ডিভাইস → **Clock** → টাইমজোন **Asia/Dhaka (GMT+6)**।
2. **NTP/time sync** চালু করে সংরক্ষণ ও রিবুট করুন।

---

## ৪. eEdu-র দিক ঠিক আছে?

1. **`ড্যাশবোর্ড → শিক্ষার্থী → উপস্থিতি → Settings → Devices`** খুলুন।
2. **status** (Active?) ও **Pending buffer** সংখ্যা দেখুন।
3. **Punch Logs** খুলুন:
   - **New/queued** → eEdu প্রসেস করছে; একটু অপেক্ষা করুন।
   - **Error** → সাধারণত key বা ম্যাপিং সমস্যা।

> **স্ক্রিনশট প্লেসহোল্ডার:** *ডিভাইস তালিকা — status, model, location ও Pending buffer কলাম।*

## তবুও সমস্যা?

| লক্ষণ | সম্ভাব্য কারণ |
| --- | --- |
| একেবারেই কিছু নেই | push URL/key ভুল, বা ডিভাইস অফলাইন |
| কিছু পাঞ্চ নেই | নেটওয়ার্ক ড্রপ; ডিভাইস বাফার করে পরে পাঠায় |
| ভুল ব্যক্তি | ইউজার আইডি ভুল — দেখুন [ইউজার আইডি ম্যাপিং](/bn/docs/hardware-guide/user-id-mapping) |
| ভুল দিন/সময় | ডিভাইসের ঘড়ি/টাইমজোন |

সমস্যা থাকলে eEdu সাপোর্টে ডিভাইসের **model, serial ও status** জানান।
