**শুরুর আগে:** ওনার/শিক্ষক লগইন, নেটওয়ার্কে চালু ডিভাইস, এবং ডিভাইসের ঘড়ি **Asia/Dhaka**-তে।

---

## ১. eEdu-তে ডিভাইস রেজিস্টার করুন

1. **`ড্যাশবোর্ড → শিক্ষার্থী → উপস্থিতি`** → **Settings** ট্যাব → **Devices**।
2. **Add Device** চেপে পূরণ করুন:

| ক্ষেত্র | কী দিতে হবে |
| --- | --- |
| **Model** | যেমন `ZK9500` |
| **Device type** | Fingerprint / Face / RFID card |
| **Location** | যেমন `প্রধান গেট` |
| **Target group** | Students, Teachers, বা দুটোই |

3. **Save** চেপে **Device Secret Key এখনই কপি করুন** — এটি একবারই দেখানো হয়।

> [!WARNING]
> Device Secret Key হলো ডিভাইসের পাসওয়ার্ড। পাসওয়ার্ড ম্যানেজারে রাখুন; ফাঁস হলে একই স্ক্রিন থেকে key রোটেট করুন।

---

## ২. ডিভাইসকে eEdu-র দিকে নির্দেশ করুন

ডিভাইসের সেটিংস (ব্রাউজার পেজ বা LCD মেনু) খুলে বসান:

| ডিভাইস সেটিং | মান |
| --- | --- |
| Communication mode | **TCP/IP** |
| Attendance mode | **Push** (Cloud) |
| Server address | `api.eedu.bd` · Port `443` |
| **Push URL** | `https://api.eedu.bd/api/v1/devices/attendance/ingest` |
| **Device Secret Key** | ধাপ ১-এর key |
| ঘড়ি | **Asia/Dhaka (UTC +6)**, NTP চালু |
| Offline buffer | **On** |

**ZKTeco/ADMS:** ADMS-এ একই সার্ভার তথ্য দিয়ে ডিভাইস তৈরি করুন, অথবা সরাসরি ডিভাইসে push URL ও key বসিয়ে ADMS বাদ দিন।

---

## ৩. সংযোগ পরীক্ষা করুন

1. ডিভাইসে একজন **পরিচিত ব্যবহারকারীর** আঙুল/কার্ড পাঞ্চ করুন।
2. **`ড্যাশবোর্ড → শিক্ষার্থী → উপস্থিতি → Settings → Devices`** → **Punch Logs** খুলুন।
3. পাঞ্চটি সঠিক নামসহ **Processed** দেখা উচিত। ডিভাইস **Active** হবে ও Serial স্বয়ংক্রিয়ভাবে ধরা পড়বে।

## ৪. ঘড়ি সেট করুন (খুব গুরুত্বপূর্ণ)

ভুল সময়ই ভুল দিনের উপস্থিতির প্রধান কারণ।

1. ডিভাইস সেটিংস → **Clock / Date Time**।
2. টাইমজোন **Asia/Dhaka (GMT+6)**, **NTP/time sync** চালু করুন।
3. আবার পাঞ্চ করে নিশ্চিত করুন।

---

## সম্পন্ন

শ্রেণির সময়ের নিয়ম অনুযায়ী শিক্ষার্থীরা **Present** বা **Late** হয়; শিক্ষকদের চেক-ইন **ওভারটাইম** হিসেবে পে-রোলে যায়। ইন্টারনেট চলে গেলে ডিভাইস পাঞ্চ **বাফার** করে পরে পাঠিয়ে দেয়।

পরের ধাপ: **[ইউজার আইডি ম্যাপিং](/bn/docs/hardware-guide/user-id-mapping)**।

> [!TIP]
> দুটি অভ্যাস বেশিরভাগ সমস্যা ঠেকায়: ঘড়ি NTP-সিঙ্ক রাখা, আর Device Secret Key পাসওয়ার্ড ম্যানেজারে রাখা।
